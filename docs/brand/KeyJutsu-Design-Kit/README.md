# KeyJutsu Design Kit

This bundle is the design handoff for **KeyJutsu**.

## Start here

1. `KEYJUTSU-DESIGN-SYSTEM.md` — human-readable canonical design system.
2. `design-tokens.json` — machine-readable source of truth.
3. `design-tokens.css` — ready-to-use CSS variables.
4. `AGENT-UI-HANDOFF.md` — condensed implementation constraints for coding agents.
5. `mockups/` — four canonical HTML mockups plus PNG previews.
6. `assets/brand/` — generated brand assets.
7. `assets/icons/` — practical app icon sizes and Windows ICO.

The KeyJutsu planning UI is branded. The armed terminal should match the user's real terminal and intentionally shed KeyJutsu branding.
